# VerSans login image update

This patch changes the login-page visual image on both desktop and mobile to the new uploaded VerSans model image.

## Files included
- `login.html`
- `images/auth-login-showcase-20261126.png`

## Install
1. Replace `login.html` in your project root.
2. Copy `images/auth-login-showcase-20261126.png` into your project's `images/` folder.
3. Deploy to Render.

No other pages or logic were changed.
